# Contributing to hLPU

Thank you for your interest in contributing to hLPU! We welcome contributions from students and alumni of LPU.

## How to Contribute

1. **Fork the Repository**: Create your own copy of the project.
2. **Create a Branch**: Create a branch for your feature or bug fix.
3. **Make Your Changes**: Ensure your code follows the existing style and premium aesthetic.
4. **Test Your Changes**: Verify that the pages load correctly and navigation is functional.
5. **Submit a Pull Request**: Provide a clear description of your changes.

## Code Standards

- Use semantic HTML.
- Maintain the premium "Heritage Network" aesthetic.
- Keep CSS variables coordinated with the main theme.
- Ensure responsive design for mobile and tablet views.

## Reporting Issues

If you find a bug or have a feature request, please open an issue in the GitHub repository.
